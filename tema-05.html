Tema 05

El modelo de caja, floats y position

📚 Fuentes: Primeros pasos en CSS (MDN) ↗ · El modelo de caja (MDN) ↗ · Floats (MDN) ↗ · position (MDN) ↗

🎬 La idea en una frase

En CSS todo son cajas: cada elemento es una caja con contenido, relleno, borde y margen. Entender cómo se miden esas cajas es el 80% del layout. Y para colocarlas: floats para envolver texto, position para sacar elementos del flujo.

🧒 Explicado como a un niño de 10 años

El modelo de caja es un regalo de cumpleaños. Cuando envuelves un regalo, no metes el juguete a pelo en una caja: pones cosas alrededor. CSS hace exactamente lo mismo con cada elemento.

  • El juguete → el contenido (el texto, la imagen).
  • El papel de relleno que lo protege → el padding (espacio por dentro).
  • La caja de cartón → el border.
  • La distancia que dejas hasta el regalo del vecino → el margin (espacio por fuera).
  • border-box → "la caja mide lo que pone en la etiqueta, punto": si la caja pone 30 cm, son 30 cm caja incluida. En el modelo estándar, los 30 cm son solo del juguete y luego hay que sumar papel y cartón (por eso da dolores de cabeza).
  • Colapso de márgenes → si tú pides 2 metros de distancia y tu amigo pide 1, la distancia final es 2: no se suman, gana el mayor.
  • display: block → el amigo que se sienta en medio del banco y estira los brazos: nadie más cabe en su línea. inline → amigos que caben todos en la misma fila.
  • Clase vs ID → la clase es un apodo (pueden tenerlo varios compis); el ID es tu DNI (solo tuyo, uno por página).

🪟 Position, con chicles

  • static → sentado en tu sitio (el de siempre).
  • relative → te levantas y das un paso, pero tu mochila sigue en tu sitio ocupándolo.
  • absolute → te vas del aula: tu sitio desaparece y los demás se reordenan. Te colocas mirando a tu madre (el ancestro posicionado más cercano).
  • fixed → te pegas con chicle al cristal de la ventana: te ve aunque todo el mundo baje las escaleras (hace scroll).
  • sticky → te quedas pegado a la puerta solo hasta que el profesor (tu contenedor) sale: entonces te vas con él.

📋 Mide una caja con las DevTools en 4 pasos

  1. Abre tu página en el navegador y pulsa F12.
  2. Pulsa el icono de la flechita y haz clic sobre cualquier elemento.
  3. En la pestaña de estilos busca el dibujito del regalo: verás contenido, padding, border y margin con sus píxeles reales.
  4. Cambia un margin a pelo ahí mismo y mira cómo se mueve la caja. Experimentar es gratis.

📦 El modelo de caja

Dos tipos de caja: en bloque (<p>, <h1>…) ocupa todo el ancho y fuerza salto de línea; en línea (<a>, <span>…) fluye dentro del texto e ignora width/height.

CapaPropiedadClaves
Contenidowidth / heightEl contenido en sí.
RellenopaddingEspacio interior entre contenido y borde. Nunca negativo.
Bordeborderborder: 3px solid black; (ancho estilo color). Hay versiones por lado.
MargenmarginEspacio exterior. Sí admite valores negativos (superposición).

📌 Estándar vs alternativo (esto te ahorra dolores de cabeza)

  • Modelo estándar (el de fábrica): width mide solo el contenido. La caja real = width + padding + border. Una caja de width: 350px; padding: 25px; border: 5px; ocupa en realidad 410px.
  • Modelo alternativo: box-sizing: border-box; → width incluye contenido + padding + borde. Lo que declares, eso ocupa.
  • Para que lo use todo el proyecto: html { box-sizing: border-box; } *, *::before, *::after { box-sizing: inherit; }

✔ Colapso de márgenes

Si dos márgenes verticales se tocan, no se suman: gana el mayor. Un párrafo con margin-bottom: 50px seguido de otro con margin-top: 30px → separación de 50px, no 80. Si das margen y "no pasa nada", sospecha del colapso. (Y para ver las cajas reales: inspector del navegador, F12.)

display: inline-block: punto medio. No fuerza salto de línea, pero respeta width/height y el padding empuja a los demás. Muy usado en botones y enlaces con área de clic grande.

🌊 Floats: el texto envuelve la imagen

float: left | right saca el elemento del flujo normal y lo pega a un lado: el contenido siguiente lo envuelve. Nació para maquetar imágenes dentro de columnas de texto (diseño de periódico). Usarlo para columnas enteras es una técnica anticuada (hoy flexbox/grid), pero debes conocerlo porque aún aparece y porque la actividad lo usa.

📌 Los dos problemas clásicos y sus soluciones

  • Elemento siguiente sube junto al float → clear: left | right | both; en ese elemento.
  • El contenedor "no envuelve" el float (el fondo queda cortado): tres remedios — el truco clearfix (.wrapper::after { content: ""; clear: both; display: block; }), overflow: auto en el contenedor, o lo moderno: display: flow-root.

📍 position: sacar elementos del flujo

ValorSe posiciona respecto a…¿Saca del flujo?
static— (el flujo normal; es el valor por defecto)No. top/right/bottom/left no tienen efecto.
relativeA sí mismo (su posición original)No: deja su hueco; solo se desplaza visualmente.
absoluteAl ancestro posicionado más cercano (si no hay, al bloque inicial = la página)Sí: los demás actúan como si no existiera.
fixedAl viewport (la ventana): se queda fijo al hacer scrollSí.
stickyHíbrido: relativo hasta cruzar el umbral (top: 0…), luego fijo dentro de su contenedorNo.

✔ z-index y detalles de examen

z-index controla qué elemento se dibuja encima (solo funciona en elementos posicionados). Con absolute, si defines top y bottom, gana top. Con sticky debes darle al menos un umbral (top, left…) o se comportará como relative. Un ancestro con transform se convierte en el contenedor de referencia de un fixed.

⚠ Museo de horrores

  • Maquetar columnas enteras con floats en 2026: para eso están flex y grid.
  • position: absolute para todo: es imposible de mantener; el flujo normal existe por algo.
  • Poner width a un elemento inline y quejarse de que no funciona.
  • Olvidar el clear y luego el "por qué este div está subido" te vuelve loco 20 minutos.
  • Pelearse con los márgenes sin saber que colapsan.

🧠 Auto-test rápido

Pulsa cada pregunta para ver la respuesta.

1. ¿Qué diferencia hay entre el modelo de caja estándar y el alternativo?
Estándar: width mide solo el contenido (padding y border se suman). Alternativo (box-sizing: border-box): width incluye contenido + padding + borde.
2. ¿Qué código hace que TODOS los elementos usen el modelo de caja alternativo?
html { box-sizing: border-box; } y *, *::before, *::after { box-sizing: inherit; } (heredado para todo el documento).
3. ¿Qué es el colapso de márgenes?
Cuando dos márgenes verticales se tocan, se fusionan y gana el mayor, no se suman. 50px + 30px = 50px de separación.
4. Diferencia práctica entre display: block e display: inline.
Bloque: ocupa todo el ancho, fuerza salto de línea y respeta width/height. En línea: fluye dentro del texto, sin salto de línea, e ignora width/height.
5. ¿Para qué sirve la propiedad clear y qué valores admite?
Evita que un elemento suba junto a un float. Valores: left, right y both.
6. Cita tres formas de conseguir que un contenedor envuelva (contenga) a sus elementos flotados.
1) El truco clearfix (::after { content: ""; clear: both; display: block; }), 2) overflow: auto en el contenedor, y 3) la forma moderna: display: flow-root.
7. ¿Respecto a qué se posiciona un elemento con position: absolute?
Respecto a su ancestro posicionado más cercano (un ancestro con position distinto de static). Si no existe ninguno, respecto al bloque contenedor inicial (la página/viewport).
8. Diferencia entre position: fixed y position: sticky.
fixed se fija siempre respecto al viewport (se queda en pantalla al hacer scroll). sticky es un híbrido: fluye como relativo hasta cruzar el umbral indicado (top: 0), entonces se pega, y solo dentro de su contenedor padre.
9. ¿Qué selecciona "li em" y qué selecciona "h1 + p"?
li em → todos los em dentro de un li (descendiente). h1 + p → un p que sea hermano inmediato de un h1 (justo después).
