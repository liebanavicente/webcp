Tema 01

¿Por qué existen los estándares web?

📚 Fuente: Currículum d'estàndards web, Chris Mills (Opera, 2008), vía UOC Mosaic. artículo original ↗

🎬 La idea en una frase

Un tipo de Opera (Chris Mills) se enamoró de enseñar estándares web y creó un curso gratuito, abierto y sin prerrequisitos… porque muchas universidades aún penalizaban a los alumnos por usar buenas prácticas. Sí, eso decía.

🧒 Explicado como a un niño de 10 años

Imagina que la web son las carreteras: los semáforos significan lo mismo en todas las ciudades y por eso nadie se choca. Los estándares web son exactamente eso: normas comunes para que tu página "circule" bien en todos los navegadores.

  • Tu página → un coche.
  • Los navegadores → las ciudades por las que circula.
  • HTML + CSS bien escritos → pasar la ITV: no es capricho, es lo que te deja circular sin sustos.
  • Tablas para maquetar y GIFs espaciadores → circular con ruedas cuadradas: el coche se mueve, pero ¿por qué sufrir?
  • El validador W3C → el examinador de la autoescuela que te dice exactamente qué está mal antes de que te multen.

📋 Para entrenar el ojo

Entra en cualquier web que uses a diario, pulsa F12 (herramientas del navegador) y mira su código. Luego piensa: ¿qué crees que cambiaría si no siguiera estándares? Respuesta corta: tú no podrías verla bien desde tu móvil.

💪 Las 5 ventajas de los estándares

VentajaQué significa en la práctica
✏️ Código eficiente Separas contenido (HTML), estilo (CSS) y comportamiento (JS). Escribes una vez, reutilizas siempre.
🔧 Fácil mantenimiento ¿Cambiar el color corporativo? Lo cambias en un solo sitio y se propaga a toda la web.
♿ Accesibilidad Personas con discapacidad (ceguera, movilidad reducida) pueden usar tu web sin esfuerzo extra.
📱 Compatibilidad Tu web funciona en Windows, Mac, Linux, móviles, TVs, consolas… Y hay más móviles que PCs en el mundo.
🔍 SEO HTML limpio y semántico = Google te adora = mejores posiciones = más negocio.

🙄 Las 5 excusas (y por qué no cuelan)

ExcusaRealidad
"No me han formado en eso" Precisamente por eso existe el curso, que es gratis. Excusa eliminada.
"Mi empresa no me deja" Con estándares la web rinde mejor en buscadores y llega a más público. ¿Puede una empresa permitirse ignorar eso? No.
"Así cobro igual" Con estándares escribes más rápido, mantienes mejor y cobras más. Decide tú.
"Es muy difícil" Mentira: es tan fácil como los métodos viejos, y con más ventajas.
"Los navegadores no los soportan" Eso era antes: los navegadores actuales los soportan todos bien.

🏛️ El museo de horrores

Lo que la gente hacía "antes" (¡y aún hoy!):

⚠ Prohibido hacer esto

  • Maquetar con tablas gigantes → las tablas son para datos, no para colocar cosas.
  • GIFs espaciadores invisibles → trucos para alinear; basura de etiquetas por todas partes.
  • Menús hechos solo con JavaScript → si el JS falla o usas lector de pantalla, adiós navegación.
  • Etiquetas <font> por doquier → estilo mezclado en el HTML = infierno de mantenimiento.

✔ Moraleja

Aprende las buenas prácticas desde el principio y evitarás desaprender cosas malas después.

🧠 Auto-test rápido

Pulsa cada pregunta para ver la respuesta. Sin trampas, que luego viene el examen.

1. ¿Cuáles son las 3 capas del modelo de estándares web y qué hace cada una?
HTML = contenido/estructura · CSS = presentación/estilo · JavaScript = comportamiento/interacción.
2. ¿Por qué NO se debe maquetar una web usando tablas?
Las tablas son para datos tabulares. Usarlas para colocar elementos añade etiquetado superfluo, dificulta el mantenimiento y empeora la accesibilidad.
3. Nombra al menos 3 ventajas de usar estándares web.
Cualquiera de estas: código eficiente y reutilizable, fácil mantenimiento, accesibilidad, compatibilidad entre dispositivos y mejor posicionamiento en buscadores (SEO).
4. ¿Qué era un "GIF espaciador" y por qué era mala práctica?
Una imagen invisible que se usaba para ajustar la colocación de elementos. Usa las imágenes para un fin que no es el suyo y genera etiquetado superfluo.
5. Verdadero o falso: los navegadores actuales tienen buena compatibilidad con los estándares web.
Verdadero. Antes era un problema de verdad, hoy todos los navegadores modernos los soportan bien.
6. ¿Quién creó el currículum de estándares web y bajo qué licencia se publica?
Chris Mills (Opera), bajo licencia Creative Commons: gratuito y reutilizable reconociendo la autoría.
