🧠 Qué añade este ejercicio y cómo está resuelto

Este ejercicio reconstruye el blog de Domestika y añade sobre la actividad 1 el formateo de texto avanzado y algo más de layout. Antes de mirar el código, esto es lo importante:

  • Las secciones ahora sí llevan margin (espacio hasta la caja vecina) y padding (espacio hasta el texto de dentro) de verdad, además del border y el background-color de la actividad 1.
  • Hay dos tipos de cita: <blockquote> para la cita larga que merece su propio bloque, y <q> para la cita corta dentro de un párrafo (el navegador le pone las comillas solo).
  • El glosario usa <dl> + <dt> + <dd> porque es una lista de pares término-definición, no una lista normal — y de paso incluye un <abbr title="…"> para explicar la sigla SEO.
  • Los datos de contacto van dentro de <address>: esa etiqueta no es para cualquier dirección, es específicamente el contacto del autor o del sitio.
  • Cada fecha usa <time datetime="2026-09-12">: el texto se lee bonito para las personas (12 de septiembre de 2026) pero el atributo datetime guarda el formato ISO para que un buscador o un lector de pantalla lo interprete bien.
